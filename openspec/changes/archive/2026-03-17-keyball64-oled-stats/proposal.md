## Why

The current OLED implementation shows a static logo on the secondary half, wasting valuable display space. Replacing it with live stats (WPM, CPM, side-aware modifiers) and upgrading the primary half with lock indicators and inverted-glyph modifier keys gives the user actionable feedback on both halves at a glance.

## What Changes

- Primary half OLED now shows: current layer, Caps Lock / Num Lock state, and held modifier keys for the side that is master (LEFT or RIGHT modifiers depending on which half is USB-connected)
- Secondary half OLED now shows: current WPM and held modifier keys for the side that is slave
- Modifier and lock-state indicators (WIN, CTRL, ALT, SHIFT, CAPS, NUM) are rendered with inverted colors (black foreground on white background) when active
- All rendered glyphs are pre-rotated 90° CCW to match the physical OLED mounting orientation (panel is rotated CCW relative to text flow)
- Rotation is applied via a build-time script that transforms font tile bitmaps, not at runtime

## Capabilities

### New Capabilities

- `oled-stats-layout`: Visual layout and rendering logic for both master and slave OLED panels, including inverted-glyph modifier/lock indicators and correct portrait-mode orientation

### Modified Capabilities

- `keyball64-oled`: Secondary half requirement changes from rendering the Keyball logo to rendering WPM/CPM stats and side-aware modifier state; primary half gains Caps Lock / Num Lock display and inverted-glyph rendering

## Impact

- `keyboards/keyball/keyball64/keymaps/default/keymap.c` — OLED render callbacks updated
- `keyboards/keyball/keyball64/keymaps/via/keymap.c` — same
- Font/glyph assets — new rotated tile variants generated by script
- No changes to keymap bindings, split transport, or trackball driver
